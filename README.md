# Obsidian RedNote (小红书图文卡片生成器)

基于 Note to RED 源码修改并增强的 Obsidian 插件，将 Markdown 笔记一键转换为小红书风格的图文卡片。

## 核心功能

### 双排版模式

- **智能分割**：无需 Markdown 标题约束，自动按内容高度计算分页位置，适合自由写作的笔记
- **按标题分割**：根据 Markdown 的二级标题自动分割内容，每页对应一个章节，适合结构化笔记

### 模板系统

| 模板 | 分类 | 说明 |
|------|------|------|
| 默认排版 | 智能分割 | 自动分页，无封面页和页脚，适合任意内容 |
| 纯白底 | 按标题分割 | 简洁风格，带页眉页脚 |
| 备忘录 | 按标题分割 | 模拟备忘录样式，带标题栏 |

在设置中切换排版模式后，工具栏只显示对应分类的模板。

### 自动分页

- 精确测量每个元素的高度，智能计算断页位置
- 标题不孤悬：当分页断点紧跟标题时，自动将标题移至下一页
- 字号调整后自动重新分页并刷新预览

### 主题与样式

- 内置 11 套主题（默认、海洋、森林、暖色、极简、赛博、星空、樱花、金属、典雅、月灵）
- 支持自定义主题（新建、编辑、预览、删除）
- 支持自定义字体
- 工具栏实时切换字体、字号、主题
- 行间距和段落间距已固化优化，无需手动调整

### 导出

- 导出单张图片或批量导出所有页面
- 支持打包下载为 ZIP

## 安装

### 方法一：BRAT 插件安装

1. 安装 BRAT 插件（社区插件市场搜索）
2. 设置 → BRAT → Add Beta plugin → 输入 `dasheng-top/dasheng-obsidian-rednote`
3. 启用插件

### 方法二：手动安装

1. 下载本仓库 ZIP 并解压
2. 文件夹重命名为 `dasheng-obsidian-rednote`
3. 放入 `.obsidian/plugins/` 目录
4. 重启 Obsidian，在设置中启用插件

## 使用方法

1. 命令面板 (`Ctrl/Cmd + P`) 搜索 "RedNote" 或点击侧边栏图标
2. 左侧编辑 Markdown，右侧实时预览
3. 工具栏切换模板、字体、字号、主题
4. 点击导出按钮保存图片

## 设置

- **排版模式**：选择"智能分割"或"按标题分割"
- **标题级别**：按标题分割模式下，选择 H1 或 H2 作为分割点
- **字体管理**：添加/编辑/删除自定义字体
- **主题管理**：控制主题显示/隐藏，新建自定义主题
- **显示设置**：控制页眉时间和页脚的显示
